# xunit.v3 4.0.0 template

Project template for xunit.v3 4.0.0, including a NativeAOT variant and its generator.

Related: [falseorfalse](https://github.com/ANcpLua/falseorfalse) is the playground solution that
compares xunit.v3 4.0.0 with TUnit side by side and carries the BenchmarkDotNet harness. Both
repos share the same xunit.v3 pin; this one is the template source, that one is the comparison.
